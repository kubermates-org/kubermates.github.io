## Responsibilities

### Code Review

- Review pull requests timely (within 48 hours for non-urgent)
- Ensure code quality and consistency
- Verify tests pass and documentation is updated
- Provide constructive feedback

### Issue Management

- Triage incoming issues
- Label issues appropriately
- Assign to appropriate maintainers
- Respond to questions and discussions

### Release Management

- Publish releases with clear changelogs
- Tag versions following semantic versioning
- Document breaking changes
- Announce major updates

### Security

- Review security advisories
- Apply security patches promptly
- Coordinate responsible disclosure
- Keep dependencies updated

### Community

- Welcome new contributors
- Help guide first-time contributors
- Foster inclusive environment
- Recognize contributions

## Decision Making

- Decisions are made collaboratively
- Major decisions require consensus from at least 2 maintainers
- Emergency decisions can be made by one maintainer if urgent
- All decisions should be documented

## Becoming a Maintainer

We welcome long-term contributors! To be considered:

- **Consistent contributions** over several months
- **Deep understanding** of the codebase
- **Demonstrated judgment** in code review and decisions
- **Community commitment** to helping others
- **Agreement** with project values and guidelines

Discuss with existing maintainers if you're interested!
