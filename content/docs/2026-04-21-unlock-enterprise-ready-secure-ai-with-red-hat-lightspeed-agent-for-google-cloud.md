  enters the era of autonomous workflows, we are excited to introduce the Red Hat
  Lightspeed Agent for Google Cloud, now available on the Google Cloud Marketplace.
  The Red Hat Lightspeed Agent for Google Cloud is an enterprise-ready tool designed
  specifically for Red Hat Enterprise Linux (RHEL) to help Site Reliability Engineers
  (SREs) and IT administrators manage their Red Hat infrastructure on Google Cloud
  using natural language. Built on the Agent-to-Agent (A2A) protocol using Google’s
  Gemini models, the agent integrates directly into the Gemini Enterprise environment.
  The agent acts as a wrapper around the Red Hat Lightspeed Model Context Protocol
  (MCP) server, allowing it to communicate securely with Red Hat Lightspeed services.
  Security and integration are at the forefront of this implementation. The Red Hat
  Lightspeed Agent runs on Google Cloud Run, so it scales automatically with your
  needs while maintaining a production-ready footprint with a stronger security posture.
  To meet strict enterprise security requirements, we have implemented: A2A protocol
  adherence: Full compliance with Google’s A2A specification for interoperable agent
  communication. Secure authentication: Integration with Red Hat SSO using OAuth 2.0
  to enable authorized access to your sensitive infrastructure data. Gemini Enterprise
  integration: This agent is designed to be utilized as a tool within the Gemini Enterprise
  interface, providing a seamless experience for users already working within the
  Google Cloud ecosystem. The Red Hat Lightspeed Agent for Google Cloud allows you
  to interact with your RHEL environment through several specialized capabilities:
  Advisor recommendations analyze system configurations and help to identify potential
  issues before they impact production. Vulnerability analysis queries and prioritizes
  CVE remediation based on real-time risk assessments of your environment. System
  inventory tracks and manages registered RHEL systems across your hybrid cloud using
  simple text commands.'
