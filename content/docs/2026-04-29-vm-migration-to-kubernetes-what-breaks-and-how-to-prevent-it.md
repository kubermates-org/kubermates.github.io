  nobody scoped the network properly before the project started. A platform migration
  turned into a multi-team coordination exercise. The firewall team needed a change
  window. The security team needed to review a network placement that changed when
  it should not have needed to. The application team discovered hardcoded IPs that
  nobody documented.'
