  developed tool. As per CNCF , a pod acts as the smallest deployable unit for containerized
  application. Each pod contains a single application instance with one or more containers
  sharing compute, storage and network resources. Pod density measures the number
  of pods a node can support while maintaining stability. First, let’s look at the
  results of this study. Pod Density: vSphere Kubernetes Service (VKS) supported 42,000
