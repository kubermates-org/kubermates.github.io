  Management (Harvester) Long-standing Known Issues - Backup/Restore Rancher v2.14.3
  is the latest patch release of Rancher. This is a Community version release that
  introduces maintenance updates and bug fixes. For more information on new features
  in the general minor release, see the v2.14.0 release notes. This release addresses
  the following security issues: Fixed a security vulnerability in Rancher''s legacy
  PRTB reconciler where removing the updatepsa permission from a RoleTemplate did
  not clean up the associated PSA ClusterRole and ClusterRoleBinding. Affected users
  could retain unauthorized ability to modify Pod Security Admission enforcement levels
  indefinitely. This issue affects installations where the aggregated-roletemplates
  feature is disabled (the default). For more information, refer to CVE-2026-44947.
  All SAML providers (Okta, Ping, ADFS, Keycloak, Shibboleth) were affected. For more
  information, refer to CVE-2026-44946. Fleet workspace initialization now runs through
  the Rancher provisioning controller path instead of webhook side effects, and workspace
  RBAC objects are generated from controller-managed creator metadata. For more information,
  refer to CVE-2026-44949. Fixed a security vulnerability (CWE-22) in Fleet''s ImageScan
  subsystem where an authenticated user with permission to create or modify GitRepo
  resources could supply path-traversal sequences in spec.'
